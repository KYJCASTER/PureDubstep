# PureDubstep 前端 (React + Vite)

## 职责范围
- pure-dubstep-client 项目目录下的所有代码
- React 组件开发
- TailwindCSS 样式
- 前端路由和状态管理
- UI/UX 实现

## 目录
/workspace → /mnt/d/ccDubstep/pure-dubstep-client

## 常用命令
```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 注意事项
- 不要修改后端代码 (PureDubstep/)
- API 请求发送到 http://localhost:8080
- 后端静态资源在 /mnt/d/ccDubstep/uploads
